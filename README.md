## Descrição
Este projeto é uma aplicação web interativa para visualização dos dados de COVID-19 no Brasil.  
O usuário pode escolher o estado e o tipo de informação que deseja visualizar, como:
- Novos óbitos
- Novos casos
- Óbitos por 100 mil habitantes
- Casos por 100 mil habitantes

Os dados são obtidos diretamente do repositório público, garantindo atualizações automáticas.  
A aplicação utiliza gráficos dinâmicos para tornar a análise simples e intuitiva.

---

## Funcionalidades
- **Selecionar o Estado** para visualização dos dados.
- **Escolher o Tipo de Informação** (novos casos, óbitos, etc).
- **Gráfico Interativo** gerado com Plotly Express.
- **Filtragem Dinâmica** dos dados por estado.
- **Interface Web** simples e acessível feita com Streamlit.

---

## Tecnologias Abordadas
- **Python**: Linguagem usada para desenvolver o projeto.
- **Pandas**: Manipulação de dados e tratamento do dataset.
- **Plotly Express**: Criação de gráficos de linha interativos.
- **Streamlit**: Desenvolvimento da interface web.
